# NArFU · 111621 中俄双语课表

正式课表网址：https://narfu-live-111621.vercel.app/

使用者已在俄罗斯手机关闭 VPN 后验证此入口可以打开并同步。旧 GitHub Pages 入口保留，加载新版后自动跳转至正式入口，避免原入口在该网络下同步失败的问题。两个入口原来使用相同后台；本次统一入口，不改动学校数据来源。

GitHub Pages 公开网页，朋友无需登录即可使用。iPhone Safari 可添加主屏幕；包含日期周切换、点击课程展开详情、教师中俄全名、教室和地址、分组筛选及语言设置。

## 自动同步

网页打开时、重新联网、返回前台（距上次检查超过一分钟）以及页面打开期间每五分钟，通过公开后台重新读取学校当前课表。点击“获取最新课表”立即重新请求学校数据，不需要进入 GitHub 启动任务；成功后显示中俄双语课程、时间、教师和教室。失败时保留本机已有课表，明确提示未同步成功，不将旧发布数据标为即时读取成功。

实时接口为 https://narfu-live-111621.vercel.app/api/timetable ，使用 Vercel Hobby 免费方案，无需学生登录，不包含私人令牌。不同的独立请求直接读取学校，仅合并同时进行的请求，不保存成功快照作为实时结果。网页关闭期间没有另外的实时轮询任务，下次打开会重新读取学校。俄罗斯当地线路需由使用者实际测试；免费方案超过用量上限时可能暂停。

GitHub Actions 仍保留原有课表构建和发布配置，作为网页初始快照及双语日历订阅来源。其定时触发未验证恢复，网页实时更新不依赖它；构建失败保留上次发布版本，不发布空课表。

公开仓库使用 GitHub Free 的标准 GitHub 托管运行器和 Pages。不要启用付费或更大规格运行器。仓库长时间无活动时 GitHub 可能停用定时工作流；脚本保留每天或课程变动时的真实校验快照。若 Actions 显示停用，需要所有者重新启用。

## 日历和提醒

`calendars/all-all.ics` 是双语日历订阅；按分组与语言提供 12 个地址，网站按钮会跟随筛选更新。它们跟随 GitHub 最近发布的快照，网页实时读取不会自动改写订阅文件。苹果自行决定日历订阅刷新时间。点击导出会下载屏幕当前课表的快照，包括刚刚同步到的课程时间。学校官方俄文订阅保留。

GitHub Pages 不能保存设备推送订阅或运行 Web Push 服务器。GitHub 版目前提供苹果日历订阅入口，不宣称已具备锁屏网页推送。旧 Cloudflare 网站已启用的通知仍由旧后台处理。本仓库不包含任何私钥、访问令牌或推送设备记录。

## 发布

在仓库 Settings → Pages 中将 Source 设为 GitHub Actions，然后运行 `Sync school timetable and publish`。`main` 分支需要允许此工作流使用仓库内容写入权限，以保留学校快照；Pages 发布使用当前工作流短期令牌，不需要个人访问令牌。

本地检查：Node.js 22 或更新版，运行 `npm run build && npm run validate`。构建时需要连接学校，不需要安装第三方依赖。

网页和自动同步迁出 Cloudflare 后，俄罗斯网络仍需在使用者的实际运营商下测试。未进行俄罗斯本地网络实测前，不保证免 VPN 可用性。
